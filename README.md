# Jogo do Número Secreto

Essa é uma versão mais avançada e completa do jogo do número secreto, com diversos recursos e ferramentas que promovem a interação entre o arquivo .js e o HTML.

## Como funciona

• Ao iniciar o jogo, um número secreto é gerado aleatoriamente.

• O usuário informa um palpite por meio de um campo de entrada.

• O sistema informa se o número secreto é maior ou menor que o valor digitado.

• O jogo contabiliza o número de tentativas até o acerto.

• Ao acertar, o usuário recebe uma mensagem informando quantas tentativas foram necessárias.

• O botão de reinício permite começar uma nova rodada com um novo número secreto.

## Funcionalidades implementadas

• Geração de números aleatórios sem repetição, utilizando uma lista de controle.

• Exibição dinâmica de mensagens na tela usando manipulação do DOM.

• Contador de tentativas com ajuste automático de singular/plural.

• Recurso de leitura em voz alta das mensagens exibidas, utilizando a biblioteca responsiveVoice.

• Reinício completo do jogo com reset de estado.

Essa atividade foi um desenvolvimento em JavaScript e HTML, como projeto final do curso "Lógica de programação: explore funções e listas" disponibilizado na plataforma "Alura".
